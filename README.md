# Проект 2: Интернет-магазин «Быстрая доставка»
Краткое описание
Проект демонстрирует навыки системного анализа в e-commerce: взаимодействие с внешними системами (платежный шлюз, склад, уведомления), проектирование API, формализацию бизнес-правил и нестандартные сценарии (автоотмена заказов).
Артефакты 
1. Диаграмма контекста (C4 level 1)
Диаграмма контекста C4
Покупатель через HTTPS оформляет заказ и оплачивает.
Менеджер через HTTPS управляет заказами.
Интернет-магазин общается с:
Платежным шлюзом (REST API для создания платежа + webhook для оповещения об оплате).
Складской системой (REST API для резервирования товаров).
Сервисом уведомлений (HTTP API для email/SMS).
2. Sequence diagram – оплата заказа
Sequence diagram для оплаты
Сценарий:
Покупатель нажимает «Оплатить».
Магазин создает платежную сессию в платежном шлюзе.
Шлюз возвращает ссылку на оплату.
Магазин перенаправляет покупателя.
Покупатель оплачивает.
Шлюз отправляет вебхук (callback) на магазин.
Магазин обновляет статус заказа на «Оплачен», уведомляет покупателя по email.
3. OpenAPI спецификация
Описание эндпоинтов: создание заказа, проверка статуса, callback для платежей.
4. Decision table – расчёт скидки
Правила расчёта скидки в зависимости от суммы заказа, количества товаров и статуса клиента (постоянный/новый).
5. User Story – автоматическая отмена заказа
Сценарий: если заказ не оплачен в течение 30 минут, система отменяет его и освобождает товары на складе.
