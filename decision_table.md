Магазин хочет давать скидку в зависимости от:
суммы заказа (S)
количества товаров (Q)
является ли покупатель постоянным (C: да/нет)

Правила (таблица):
| Сумма (S)       | Кол-во товаров (Q) | Постоянный клиент (C)| Скидка |
| S < 3000        |        любой       |         нет          |   0%   |
| S < 3000        |        любой       |         да           |   3%   |
| 3000 ≤ S < 5000 |       1 или 2      |         нет          |   0%   |
| 3000 ≤ S < 5000 |         ≥ 3        |         нет          |   5%   |
| 3000 ≤ S < 5000 |        любой       |         да           |   7%   |
| S ≥ 5000        |       1 или 2      |         нет          |   5%   |
| S ≥ 5000        |         ≥ 3        |         нет          |  10%   |
| S ≥ 5000        |        любой       |         да           |  12%   |


Условия применения: скидка применяется к итоговой сумме заказа до вычета других скидок (если бы были акции). Максимальная скидка 12%.
